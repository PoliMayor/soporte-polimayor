☁️ Almacenamiento en Google Drive

Conecta la cuenta polimayor2026@gmail.com para que cada soporte se guarde automáticamente en Google Drive, organizado por taquillera / año / mes / día.

⚙️ Configuración inicial (una sola vez):
1. Ve a console.cloud.google.com e inicia sesión con polimayor2026@gmail.com
2. Crea un proyecto llamado SoportePolimayor
3. Activa la Google Drive API en "APIs y servicios"
4. Ve a "Credenciales" → "Crear credenciales" → "ID de cliente OAuth 2.0"
5. Tipo: Aplicación web · Agrega en orígenes autorizados: http://localhost:3000
6. Copia el ID de cliente (termina en .apps.googleusercontent.com)
7. Pégalo abajo y guarda
⚪ No conectado — los soportes se guardan solo en Supabase

☁️ Conexión con Google Drive

Las imágenes se guardarán automáticamente en Google Drive de polimayor2026@gmail.com, organizadas por carpetas: SoportesPolimayor / Taquillera / Año / Mes / Día

Pasos para activar Google Drive:
1. Ve a console.cloud.google.com → inicia sesión con polimayor2026@gmail.com
2. Crea un proyecto nuevo llamado SoportePolimayor
3. Ve a APIs y servicios → Habilitar APIs → busca Google Drive API → Habilitar
4. Ve a Credenciales → Crear credencial → ID de cliente OAuth 2.0
5. Tipo: Aplicación web · Nombre: SoportePolimayor
6. En "Orígenes JS autorizados" agrega: http://localhost:3000
7. Copia el ID de cliente (termina en .apps.googleusercontent.com)
8. Pégalo abajo y guarda
